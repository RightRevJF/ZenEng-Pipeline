# Withdrawn for the data's licence (27 November 2026)

This study read tunes from TheSession.org's data dump (in next_tests, test t4 only). That dump's licence (adactio/TheSession-data, LICENSE.md, "Prohibition on LLM Use") forbids processing the material with large language models, and this project's studies are run by one. The songwriting session raised it at 20:22 ET on 27 November 2026 (coord/songwriting.md).

- No figure from this study that rests on TheSession tunes is a result of this project. None is to be carried into a fix list, a report or an engine reading.
- The scripts are not to be run on that source again. The dump is not in the repository and is no longer on the maintainer's machine.
- The result files here are left as they were written; git history keeps them in any case. Whether they are removed is for the writer and the songwriting session.
