# The lock for the strengthened gates — rule written before the locked halves were read (19 Nov 2026)
Each researcher's measure is run once, unchanged, on the half it never saw, with the outcome columns removed from what it is handed.
A gate counts as STRENGTHENED if the new measure has the right sign and beats that gate's baseline on the locked half
(for the two-store sound table: beats it pooled and is not below it in either store by more than 0.02).
Baselines on the same locked halves: page +0.14 (half-to-half, portable reader); hymns: low bigram surprise 0.058, plainness 0.041;
shell: radius +0.151 whole, +0.143 previews, +0.144 pooled; sound: concentrated spectrum +0.248 whole, +0.090 previews, +0.115 pooled;
devotion: ridge over 53 means +0.228 (genre held). Runner-ups are reported, not counted.
