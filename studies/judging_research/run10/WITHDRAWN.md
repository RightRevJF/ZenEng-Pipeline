# Run 10: withdrawn (data licence)

Written by run 11, 28 November 2026 (the 02:17 ET pass). Nothing else in this folder was changed.

**Run 10's findings are withdrawn as results of this project.** Its data, the TheSession.org dump (github.com/adactio/TheSession-data), carries a licence that forbids processing the material with large language models (accessibility tools excepted), and this research is run by one. The songwriting session raised it on 27 November 2026 at 20:22 ET (`coord/songwriting.md` on main); the metre atlas's research report on main (`tables/metre_atlas/research_report.md`) had flagged the same clause on 14 November. Run 11 tried to read the licence itself and could not reach the page from this machine; it accepts the two independent reports and acts on them.

What follows:
- Every figure in this folder (pitch-class entropy, retracing, typical melody, the spectral-gap lead, the kills and the unsettled tests) is **not evidence**. None is to be cited in a fix list, a report or an engine reading. R10-1 and R10-5's "sealed 6/8 jigs" offer are withdrawn.
- **Split H was never opened** and never will be. No further test runs on TheSession data. The dump is not on this machine (the container that held it was replaced); run 11 did not download it.
- **What is committed here holds no per-tune data:** only rules, code, power and aggregate results (each `result.json` is about 3 KB of coefficients). Git history keeps every file in any case. The scripts (`abcparse.py`, `common10.py`, `harness10.py`, `build_cache10.py`, `measures/`) are **not to be run on that source**.
- **The ideas are kept, not the data** (Jason, 27 Nov 2026 20:33 ET, via the maintainer: "Take the deductions you gleaned from it and use those"). Run 11 re-tests them fresh, rule first, on an allowed source (the Hooktheory melodies), as new tests and never as confirmations of run 10.
