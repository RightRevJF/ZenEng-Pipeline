# Song as a shape, second run on fresh songs — predictions written 19 Nov 2026 before the set was measured

Set: the Yu et al. lyrics-melody set (Lakh + Reddit MIDI, ~11,700 songs, each syllable tied to its note), joined by
title and artist to the Hot 100 record; 2005 or earlier; love known; >= 60 syllables the lexicon holds; one entry per
song; every title already used in the first run removed. Yardstick G as before (love + covers, each within era).
Same six-coordinate path, same measures, same controls (year, note count).

 M7  word and tune, over shuffled words (the form predicted last time)     +
 M7r word and tune, unshuffled (the form that read +0.22 last time)       +
 M3  curvature                                                            +   (the reverse of my first guess)
 M4  persistence                                                          -   (the reverse of my first guess)

Pass, for each: predicted sign in both halves, p < .05 in each, pooled p < .0125 (four tests). Else fail.
Known weakness, stated before measuring: this set gives no bar lines, so the place-in-the-bar coordinates are read
from running time and will be wrong for songs not in four or not starting on a bar. Titles without an artist in the
file name are taken only where one Hot 100 song has that title. Nothing goes into the engine on this study.
